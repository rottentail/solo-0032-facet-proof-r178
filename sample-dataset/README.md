# Facet Proof 多件装配合成视觉样本集

本目录是一套由 Facet Proof 渲染后端生成、可独立核验的多件装配合成视觉样本。
每个样本都包含**互相对应的 RGB、深度和部件标注**三个语义通道（原始字节 +
PNG 预览，共六个文件），并附带生成依据，使接收者无需连接服务即可读取与核对。

## 目录结构

```
sample-dataset/
├── dataset-manifest.json        # 全集清单：样本索引、覆盖矩阵、冻结摘要
├── S01/ … S10/                  # 每个样本一个自包含目录
│   ├── sample-manifest.json     # 样本级清单：镜头、请求、对象映射、通道校验和、交叉核对
│   ├── plate-bundle.zip         # 离线核验包（两份元数据 + 六个通道，facetreader 直接读取）
│   ├── plate.json               # 图版元数据（通道描述符、统计、visual_hash）
│   ├── seal.json                # 冻结快照（网格/材质/镜头/光照闭包及 content_hash）
│   ├── reader-report.json       # 独立读取器 facetreader 的核验结论
│   └── channels/
│       ├── color.png  color.rgb    # RGB：PNG 预览 + sRGB 原始字节（每像素 3 字节）
│       ├── depth.png  depth.f32    # 深度：PNG 可视化 + 小端 f32 摄像机前向距离
│       └── object.png object.u32   # 部件：PNG 伪彩 + 小端 u32 部件编号（0=背景）
└── …
```

## 通道语义（每个图版内逐像素对齐）

| 通道 | 原始格式 | 含义 |
| --- | --- | --- |
| `color.rgb` | 8 位 sRGB，3 字节/像素 | 线性光照计算后转回 sRGB 的颜色 |
| `depth.f32` | 小端 IEEE-754 f32，4 字节/像素 | 摄像机前向距离；背景为正无穷 `+inf` |
| `object.u32` | 小端无符号 u32，4 字节/像素 | 部件编号，作用域仅限本图版；`0` 为背景 |
| `*.png` | RGB PNG | 三个原始通道各自的可视化预览，像素与原始通道一致 |

部件编号到装配部件（placement key、网格 id、材质 id）的映射记录在
`sample-manifest.json` 的 `objects` 字段，并与 `seal.json` 的冻结闭包严格对应。
编号按冻结后的 placement key 字典序从 1 开始；某部件在特定视角被完全遮挡时
不会出现像素编号，但其映射仍保留在清单中（例如 S04 的部件 2）。

## 覆盖矩阵（10 个样本）

- **镜头**：透视（S01、S03–S05、S07–S10）与正交（S02、S06）；四个机位、
  32°/40°/45°/52°/60° 多档视场。
- **材质**：哑光（高粗糙度/低高光）、缎面、高光（粗糙度 0.12、高光 0.85）；
  同时覆盖单面与 `two_sided` 双面材质的剔除路径。
- **采样**：`samples=1` 与 `samples=2`（2×2 超采样），画布含方形与矩形，
  边长 128–200，均在服务 512 上限内。
- **几何**：角形支架、圆柱立柱、横销、锥台把手、六角座、经纬球、垫板七类
  过程化网格组合为 5–6 件装配；单装配 256–412 个三角面，低于 40000 上限。

同一场景在不同采样/镜头下成对出现（S01/S03、S05/S06、S07/S08、S09/S10），
可用于比对超采样与投影差异；每个样本对应**各自独立的冻结 seal**
（全集 10 个互不相同的 `seal_hash`）。

## 生成依据与防混入保证

样本由仓库内 `samplekit/` 工具通过 Facet Proof 的真实路由接口驱动生成，
关键事实全部落在清单里，可逐项复核：

1. **冻结优先**：每个样本先把可见网格、材质、镜头、光照闭包复制进 seal
   （`seal.json` 的 `content_hash`），之后任何草稿修改、材质改色、装配分叉都
   不影响旧 seal；服务本身拒绝编辑已封存装配（错误码 `sealed`）。
2. **跨运行不换几何**：`sample-manifest.json` 同时记录 `spec_hash`（样本定义
   的哈希）与 `seal_hash`。工具重跑时若发现目录定义已变而旧 seal 仍在，会把
   样本标记为 `drifted` 并保留原冻结几何，绝不在同一样本 id 下替换成新几何。
3. **重复曝光拦截**：每个样本使用固定幂等键 `sample-<id>`。同键重发且请求
   一致时返回同一曝光；同键指向不同请求被服务拒绝（错误码 `key_conflict`），
   因此重复曝光不会产生第二份图版，也不会重复预留画布额度。
4. **完整度闸门**：只有六个通道齐全、服务端 `/verify` 通过、且独立读取器
   `facetreader` 核验通过的图版才会写入本数据集。缺通道、失败或被读取器拒绝
   的结果停留在工作日志的非 `complete` 状态，不会被导出。
5. **中断可续**：渲染按高采样画布的 64×64 分块持久化。进程中断后重跑工具会
   先回收过期租约（`worker/recover`），再在同一冻结输入、同一请求与同一渲染
   定义下复用已提交分块；只有整幅画布完整且租约有效才生成最终图版。
6. **确定性**：对同一冻结 seal 以相同请求再次渲染，六个通道的 `visual_hash`
   完全一致（已在 S03 上验证）。

## 接收者独立核验（不依赖服务、不导入服务私有校验）

使用仓库自带的独立读取器，只依赖 Python 标准库：

```sh
python3 -m facetreader ./sample-dataset/S05/plate-bundle.zip --output ./received
# 有效退出 0，拒绝退出 2；输出 summary.json / provenance.json / picks.json / color.png
```

读取器自行检查 ZIP 边界、PNG 解码、六个通道的字节校验和、原始通道尺寸、
深度/编号语义（背景必须为 `+inf`、前景深度有限为正、编号均能解析到冻结闭包）、
覆盖像素统计以及 seal/plate/lens 各级哈希链。它明确区分**内部一致性**与
**外部真实性**：核验通过只说明包内事实自洽，不证明来源身份或当前审阅状态。

对整个数据集做离线复核（同样只读取磁盘文件）：

```sh
python3 -I tools/run_samplekit.py audit --dataset ./sample-dataset
```

该命令重算每个通道与 bundle 的 SHA-256、比对 `seal_hash`，并对每个 bundle
调用 `facetreader`，输出每样本与全集的 `all_valid` 结论。
